# 自适应表单布局

新生成的 DSL 使用 `form.layout.sizing: "adaptive"`。正常新建草稿的原生投影会：

- 为桌面、移动端的表单布局列明确设置 `colsStyle[].value = "auto"`。
- 让可见编辑控件的外层以 `flex: 1 1 0; width: auto; min-width: 0` 伸缩。
- 让描述、单位、按钮等保留内容宽度，保留显式换行和零宽伴随控件。
- 保留字段身份、类型、必填、默认值、只读权限、事件、行列顺序与合并关系。
- 保留 Source Grid、宽度权重与原 `contentFlow` 尺寸作为来源证据。

没有 `sizing` 标记的旧 DSL 继续走原有宽度策略。程序化映射可用
`draftSourceDraft(source, { layoutSizing: "source" })` 明确生成兼容模式；
不会自动改写已有 DSL、模板、执行报告或锁。

## 原生标题样式

当前 QAS fieldset 在横向布局下仍生成桌面 `8em`、移动端 `6em`，
普通 `labelStyle.width = "auto"` 会被覆盖。固定的 CSS 片段同时处理
`.ele-xform-fieldset-label` 及它的直接文字 `span`，使用 `width: auto !important`
和 `max-width: none !important`，允许长标题换行。

横向字段的直接标题包装允许收缩，并最多占其可用宽度的一半，以保留输入空间。
这里的相对上限不是标题固定宽度；短标题按内容占位。规则使用直接子级选择器，
不将该上限错误施加给横向复合控件内的纵向标题。

样式由原生内置 `div` 的 DOM 属性承载固定 `<style>`，不包含业务 HTML 或
JavaScript，不增加业务 `fdFields`。不再使用没有字段 UUID 的 HTML 控件：
原生设计器保存会把该控件压缩成空引用，导致 CSS 丢失。内置容器的属性可在
原生保存和重新装配后保留。外层 `div` 使用目标主表名摘要生成唯一标记；它与 `main` 同属外观节点，
并位于 `main` 之前。规则通过 `.mk-adaptive-摘要 ~ *` 限定同一外观节点下
后续主表内容；只有带固定 `mk-adaptive-main-field` 标记的主表字段外层接受
标题与编辑器规则。明细内部不加该标记，保持原生表头高度、换行和列布局。
这些规则不改变其他表单或全站样式。

`main` 必须保持外观节点的直接子级。NewOA 设计器把它渲染成 `.receiver`，
原生明细表的横向布局依赖 `.ele-xform-appearance > .receiver`；在两者之间
增加包装层会让编辑页的列、勾选框及序号纵向展开，而预览可能仍然正常。

回读会核验双端作用域、唯一载体、完整固定 CSS-only 内容、
标记与主表的同级先后顺序、主表字段标记、可渲染节点结构，以及自动列宽、编辑器／描述外层和内容顺序。
载体隐藏、删除、重绑定、注入额外脚本或宽度退回固定值都会失败。

源文本标题的对齐和字号单独迁移。明确的标签字号（px）及标签/所属表格单元格的
`text-align`、`align` 形成来源事实，标签自身的 CSS 优先；旧 HTML 中未加引号的
`align=center` 同样保留。DSL 使用有类型限制的 `fontSize`、`textAlign`，不透传
任意源 CSS。桌面和移动端都保存内容样式，移动端另保留 `alignDesc`。
两端内容样式及对齐控件属性均参与回读，源信任检查拒绝审查阶段丢弃这些事实。
一对一字段标签继续使用既有原生标题合并，字号和对齐转入有类型限制的主字段
`titleStyle`，两端原生标题样式参与独立回读。独立文本标题仍使用说明控件，
不为保留样式而增加重复标签，也不改变字段值、权限或计算规则。

离线回归入口为 `native-style-save.test.js` 和 `description-presentation.test.js`。
前者重放真实原生布局保存、重新装配及再次保存，覆盖自适应和“其他”伴随控件样式；
后者从 XML 经过审查、dry-run、假客户端执行及回读，重放双端真实说明文本组件，
并包含字号/对齐丢失、移动端差异和脚本注入反例。这些测试不修改线上模板，
不替代真实保存/发布与页面验收。

## 明细表内部列宽边界

上述自动列宽针对表单布局 Grid。明细表自身的 `columnWidth/columnSetting`
是另一条原生配置路径；当前设计器会把 `"auto"` 拼接为 `autopx`，
运行时未配置又默认回到 142px。不能把删掉宽度参数称为明细表自动列宽。
本次保留该组件原有配置及单独审批的建议列宽，不写入未经证明的 `auto`。
明细表所在的布局列、外层区域与标题仍采用本次自适应规则。
